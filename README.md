## Preview

Open `dist/index.html` in a browser, or serve the `dist` folder with any local web server. With Python installed, run `python -m http.server 8765 --directory dist` from this project folder, then visit `http://localhost:8765`.

## Key files

- `dist/index.html`: résumé-based content, five Project Experience tiles in field/delivery/design/systems study/thesis order, experience, education, research, and contact links.
- `dist/phoenix-housing.html`: compact Phoenix Courtyard Housing academic project page with an overall render, structural section, façade drawing and physical model, service-routing concept, and original presentation photograph. Its tile is Project 04, before the older railway thesis (Project 05).
- `dist/railway-station.html`: dedicated thesis page with the complete gallery and an accessible drawing/visualization comparison slider. The comparison explicitly identifies different project views rather than suggesting an exact before-and-after match.
- `dist/site-coordination.html`: construction experience overview, contribution areas, and six supplied field photographs with full-size image links.
- `dist/architectural-work.html`: dedicated third-tile page with three residential design visualizations, responsibilities, full-size image links, and navigation back to Project Experience.
- `dist/styles.css`: responsive editorial layout, flat charcoal/bronze styling, touch-friendly controls, and reduced-motion support.
- `dist/script.js`: current year, active navigation, mobile menu, deep links into experience responsibilities, and a project comparison slider supporting pointer drag, touch, and keyboard.
- `dist/construction-background.js`: the original SVG backdrop and construction sequence. Desktop cursor position controls progress and gentle depth movement. A native range slider provides touch and keyboard access. Activity blends between groundwork, material lifting, and roof inspection. During inspection, a bronze grid fades across the roof and upper façade; a scan window follows the drone and four fixed surface points briefly light up. The grid is drawn once and its visibility and marker rings update with the existing animation loop. Separate activity clocks keep inactive plant still and animate the working actors at up to 24 fps, reusing the static model. The depth layers keep the tower and jib attached and preserve crane-footing occlusion. Motion stops when the hero is out of view or the tab is hidden. The Pause motion button freezes site activity, scan signals, and cursor depth; the slider still works immediately.
- `dist/assets/logo.svg`: custom architectural D monogram, used in navigation and as the favicon.
- `dist/assets/`: local project images, illustrative images, and the supplied résumé PDF. The `railway/` folder contains supplied thesis visualizations and drawings; `site/` contains supplied field-experience photographs; `design/` contains three selected residential design visuals; `phoenix/` contains six selected academic project visuals. Phoenix technical drawings use lossless WebP encoding, the render and model image use quality-90 WebP, and the presentation JPEG is copied unchanged. Selected PDF figure boundaries, dimensions, and annotations are preserved. Images from the interior folder are converted to WebP with their source dimensions and orientation preserved. The source photographs are not retouched or AI-generated.
- `.github/workflows/deploy-pages.yml`: publishes the `dist` folder to GitHub Pages whenever `main` is updated.
- `.openai/hosting.json`: static output configuration retained for optional Sites hosting.
